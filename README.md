# Twitter Sentiment Analysis

A Machine Learning project that classifies tweets into Positive, Negative, and Neutral sentiments.

## Features
- Logistic Regression model with 85% accuracy
- TF-IDF vectorization for text processing
- Interactive live prediction using Streamlit

## Dataset
74,683 real tweets from Twitter with sentiment labels.
